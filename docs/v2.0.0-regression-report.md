## Review 修复补记(2026-07-31,主对话 review 后发现并修复)

Review 在分支上独立复验(含端到端抽查)发现 3 个缺陷 + 1 个零碎项,均按 TDD(先 RED 测试)修复,新增 4 条测试,全量 292 → **296 全过**:

3. **图包审计目录硬编码 `images/`**:`--images-out-dir Image` 时审计仍扫 `images/`(Windows 靠大小写不敏感侥幸正确)。改为从引用路径推导公共父目录(回退 `images`);测试 `test_unreferenced_audit_follows_reference_dir`。

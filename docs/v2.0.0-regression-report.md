## 与计划数字的差异说明

1. **B157 code_fence = 40 而非个位数**:277 条锚点误报**全部清零**;40 条来自 v2 新增的"围栏碎片化"检测——B157 的 MinerU 输出有 148 个围栏块,其中 40 对相邻(间隔 ≤3 空/短行),是真实的分页切碎告警,非误报。误报面:277 → 0。
